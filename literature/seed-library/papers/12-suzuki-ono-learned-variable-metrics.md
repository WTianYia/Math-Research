# Learning Variable Metrics for Convergent Proximal Splitting Algorithms

Yodai Suzuki、Shunsuke Ono · arXiv:2610.22204v1（2026），主分类 eess.IV

**阅读依据**　预印本第 3.1、3.2 节，命题 3.1、3.2 与定理 3.3、3.4。

**方法要点**　每个问题实例一次预测少量代表度量，通过逆度量插值得到逐步度量，并对代表度量做谱缩放。相应的 PG 和 PDHG 迭代在给定条件下弱收敛。

**对照任务**　对照每次迭代由当前状态生成并验收度量的方案。逐项核对度量生成、序列变差、谱约束和最终收敛结论。
