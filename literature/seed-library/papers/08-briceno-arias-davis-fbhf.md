# Forward-Backward-Half Forward Algorithm for Solving Monotone Inclusions

Luis M. Briceño-Arias、Damek Davis · arXiv:1703.03436v3（2018）

**阅读依据**　预印本摘要与正文导言。

**方法要点**　将最大单调、余强单调和另一单调项纳入同一个三算子分裂，利用算子结构安排前向求值。

**对照任务**　从原始 FBHF 的更新式开始，记录两个前向算子各在哪些点求值，并区分固定步长版本和回溯版本。
