# Dual averaging algorithm with memory mechanism for nonsmooth optimization problems

Yan Tang、Jinming Wang · Communications in Nonlinear Science and Numerical Simulation 163, 110573（2026）

**阅读依据**　公开摘要与出版页贡献概述。

**方法要点**　在非光滑凸优化的对偶平均子问题中，用历史迭代点构造轨迹相关的 prox 项。AMDAA 在这个框架内引入距离自适应参数。

**对照任务**　对照 Xiao 的 RDA 和 DADA，分别核对历史项怎样移动 prox 中心、距离估计怎样调整步长，以及两者联动时稳定性需要哪些条件。
