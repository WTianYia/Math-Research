# An adaptive inertial shrinking projection algorithm for monotone inclusions in reflexive Banach spaces

Yan Tang、Jinming Wang · Optimization（2025 年在线发表）

**阅读依据**　出版页摘要。

**方法要点**　将惯性、自适应步长和 Bregman 收缩投影用于反身 Banach 空间的单调包含，并给出强收敛结果。

**对照任务**　关注历史外推点怎样进入收缩集合，投影中心如何选，以及空间、核函数与步长假设各自在哪里使用。
