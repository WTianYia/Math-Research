# Variable Metric Quasi-Fejér Monotonicity

Patrick L. Combettes、Bằng Công Vũ · arXiv:1206.5705v2（2012）

**阅读依据**　预印本摘要与 Suzuki–Ono 对引理 2.3 和定理 3.3 的引用定位。

**方法要点**　为随迭代变化的 Hilbert 度量建立准 Fejér 分析框架。

**对照任务**　用它核对学习型度量论文实际验证了哪些谱界、跨步不等式和可求和误差，并检查弱聚点条件怎样给出全序列收敛。
