# 数学文献日报种子库

这套材料用于初始化每日筛选。先读[日报执行提示词](DAILY_PROMPT.md)，再按方向读下面的文献卡。每张卡提供书目信息、阅读范围、方法要点、比较任务和官方原文入口。

建议先读两篇 Tang–Wang 的公开论文，再读 Suzuki–Ono 的第 3 节。前两篇分别用来理解记忆正则化和惯性投影，第三篇用来区分不同的变度量生成机制。

本库覆盖 14 篇公开论文。其中 3 篇附可重新分发的 PDF，版本与许可见对应文献卡。其余 11 篇从卡片中的官方原文入口阅读，部分出版社页面可能需要机构访问权限。
