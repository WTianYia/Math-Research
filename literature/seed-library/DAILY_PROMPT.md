# 数学文献日报执行提示词

请维护数学优化文献日报和论文追踪表。以 [种子论文目录](README.md) 校准相关性，优先寻找与这些工作直接可比较的更新机制、可迁移的证明和可复现的实验基线。种子文献是长期参照，日报记录实际公告中的新稿和重要修订。

## 追踪方向

1. **DA、镜像下降与随机优化。** 追踪 dual averaging、mirror descent、FTRL、动态正则化、距离自适应步长和随机一阶法。分清历史信息进入梯度累积、外推点、移动 prox 中心或 Bregman 核的哪一处。对偶状态直接影响极限的 lazy dynamics 也纳入补扫。
2. **Banach 空间与惯性投影。** 追踪 reflexive Banach space、Bregman projection、shrinking projection 和 multi-step inertia。记录空间和核函数的假设、历史项怎样进入投影集合、强收敛到哪个解，以及每步投影的成本。
3. **单调包含、算子分裂与解选择。** 追踪 FBHF/FBF、projective splitting、Halpern、moving anchor、Tikhonov、复合 DA 的指定解选择、方差缩减分裂。比较算子分解、锚点来源、步长或线搜索、极限点和每步求值数。谱预条件或谱归一化外梯度在能对照算子条件时纳入。
4. **带收敛保证的学习几何。** 追踪 learned variable metric、learned mirror map、warped resolvent、relative smoothness 和 Bregman 近端方法。区分每实例固定、事先构造变度量序列、根据当前迭代逐步生成三类。记录谱界、跨步变化控制、验收机制与收敛结论。

## 每期检索

- 以 arXiv 已发布的公告批次为单位，主扫 `math.OC` 的新稿和交叉列入。用上述关键词补扫 `math.FA`、`math.NA`、`math.DS`、`stat.ML`、`cs.LG` 和 `eess.IV`。 [math.OC 新稿](https://arxiv.org/list/math.OC/new) · [arXiv 公告规则](https://info.arxiv.org/help/availability.html)
- 日报日期采用 `Asia/Singapore`。记录官方公告日期、实际扫过的分类及批次、抓取是否成功。首期覆盖截至 2026-11-09 可核验的最近公告批次。随后从上次成功覆盖的批次继续，补扫错过的公告。
- 按 arXiv 主编号跨分类去重。迭代式或定理实质变化的新版记为更新，保留版本与日期。

## 收录规则

每期收录 0–5 篇。A 类是直接可比的近邻，最多 2 篇，核对算法与定理正文。B 类有具体可迁移的引理、算法组件或实验基线，写明迁移前提。只能获取摘要的条目标为“摘要初筛”，将需要核对的公式和定理列为待查。

每篇保留英文题名、作者、arXiv 编号和版本、公开原文链接，用中文写三点。

1. 它解决什么问题，改了哪一步。能核对时给一条关键公式。
2. 关键假设和结论是什么。区分强弱收敛、末次与遍历结果、目标差、算子残差与驻点指标。写清阅读范围，给出节、算法或定理编号。
3. 它对哪条追踪方向有用，最值得与哪篇种子或已收录论文并排比较。把作者的结论和你的推断分别标明。

## 归档和追踪表

首期路径为 `literature/2026-11-09.md`，后续用 `literature/YYYY-MM-DD.md`。同步论文追踪表的数据，保留日期、方向、题名、作者、arXiv 主编号、版本、优先级、原文链接和日报链接。沿用现有的日期和方向筛选，以及标题、作者、arXiv 编号检索。

区分“有公告但无入选”“无新公告”和“抓取失败”。完成归档后核对仓库中的文件链接与追踪表记录。如果没有仓库写入权限，交付可提交的 Markdown 和可导入的追踪表记录，并标明归档状态。
